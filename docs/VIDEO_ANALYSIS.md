## 官网内容决策

- 首屏定位为“面向新手的 MMD 创作项目”，突出 Android 端创作方向与介绍视频，不承诺已完成实机效果。
- 功能标题围绕导入/动作、多角色、三种光影展开；所有视频功能按项目方确认可用介绍；AI 额外标明 API 和可能的费用。
- 画面区命名“视频里的创作过程”，每张图标时间码、原帧来源和“功能示意，非实机截图”。不把占位角色替换成虚构人物渲染。
- 使用教程是“按视频理解创作路径”，不是伪造逐项可点击的 APK 操作说明。格式、设备门槛和完整实机教程列待确认。
- APK 缺失时保持“即将开放下载”。版本号、APK 大小、发布日和 SHA256 均显示“待发布/待提供”，无空壳下载地址、无假更新日志。
- 官网展示“测试介绍视频已整理”的内容公告，只讲官网内容，不冒称软件版本更新。
- QQ 和作者直接取视频公开内容，站内提供复制 QQ 与申请备注；不自动发消息或打开未知外链。
- 当前服务器已有会员 API 及后台，但本次官网静态独立，账号/会员入口不开启、不暗示安卓已完成对接，也不调用本机地址。

## 视觉与体验分析

视频使用深海军蓝底、青/紫渐变、细线框、半透明矩形、圆角按钮、简体中文和线条角色。官网延续青绿与少量紫色，以更大留白、清晰文字层级、有限的滚动渐显和真实视频画面建立视觉重点。装饰图形不是软件界面；不生成假聊天、假下载人数、假评价或性能指标。

视频每 3–4 秒换一个主题，信息密集、竖屏文字较细。官网补充静态说明、时间章节跳转和可放大原帧，让手机用户自行选择观看顺序；视频点击后加载，无有声自动播放，无滚动视频背景。开启减少动态效果时禁用平滑动画。
